# Governance

Metacodes is currently owner-maintained. The repository owner appoints maintainers,
controls releases, selects the project license, and has final responsibility for
security and compatibility decisions.

Kernel-boundary, public API, ABI revision, formal-governance, TinyKG contract, and
benchmark-promotion changes require maintainer review plus executable evidence.
Ordinary implementation decisions may be delegated through CODEOWNERS after public
launch. No plugin or host extension may self-authorize permission, budget, formal,
or memory-governance changes.

This file documents the present model rather than promising permanent governance.
Material changes will be recorded in the changelog.
