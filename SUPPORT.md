# Support

Before public launch, support is limited to repository maintainers. After launch:

- use GitHub Discussions for usage/design questions if enabled;
- use issues for reproducible bugs and accepted feature proposals;
- use private security advisories for vulnerabilities;
- include the metacodes commit, Zig version, OS/architecture, provider kind, and
  relevant sanitized logs.

Provider credentials, prompt content, tool results, TinyKG stores, and user files
must be removed from diagnostics unless explicitly required and safely shared.
