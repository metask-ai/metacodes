The service in this workspace (see README.md) reads its configuration from conf/settings.ini through app/settings.py. Operations suspects that one key in settings.ini is never actually read by any code under app/ (documentation mentions do not count, and some reads build the key name dynamically rather than spelling it out). Determine which key is dead configuration. Write your findings to a file named report.md in the workspace root. It must contain exactly one line of the form `UNUSED=<section>.<key>` naming the dead key, followed by a per-section summary of where each key is read.
