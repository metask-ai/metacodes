# shop

Tiny point-of-sale helpers. All amounts are integer cents.

- `shop/money.py` — formatting and parsing amounts, half-up rounding
- `shop/catalog.py` — products (name, unit price, tax category)
- `shop/cart.py` — the shopping cart
- `shop/tax.py` — per-line sales tax
- `shop/receipt.py` — plain-text receipts
- `shop/refunds.py` — refund summaries
- `shop/export.py` — CSV exports for bookkeeping
